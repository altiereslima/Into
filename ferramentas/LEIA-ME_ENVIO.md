# Como enviar ao GitHub (quando o Claude não tem acesso direto)

**Primeira vez:** extraia `Into_repositorio_completo.zip` (já contém o histórico git) e dê dois cliques em
`ENVIAR_PARA_GITHUB.bat`. Na primeira execução o Git abre o navegador para você entrar no GitHub.

**Etapas seguintes:** coloque o novo `Into_etapaNN.bundle` dentro da pasta `Into` e rode
`ENVIAR_PARA_GITHUB.bat` de novo: ele incorpora os commits do bundle e envia.

Alternativa sem linha de comando: GitHub Desktop → *File → Add local repository* → escolha a pasta `Into`
→ *Publish repository* / *Push origin*.
